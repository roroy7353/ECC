# Coupang Partners Reels Planner

Turn one product (or one product category) into a shoot-ready short-form video plan for the Korean market: trend check, hook, scene script, caption, hashtags, and a shoot checklist.

## When to Activate

- planning a 쿠팡파트너스 릴스, 쇼츠, or 틱톡 video
- turning a product link or product name into a review, recommendation, or "추천템" video
- needing a hook, a scene-by-scene script, a caption, hashtags, or a shoot checklist for affiliate content
- batching a week of affiliate Reels around one theme (시즌, 월급날, 자취템, 육아템 등)

## Non-Negotiables

1. **Disclose the affiliate relationship.** Every caption and every video carries a clear commission notice (see Compliance). A hidden disclosure is a failed deliverable.
2. **Never invent product facts.** Specs, price, rating, review count, and "최저가" claims come from the product page or the user. If a fact is not provided, mark it `[확인 필요]` instead of guessing.
3. **No unsupported claims.** No medical, weight-loss, or efficacy claims; no "1위", "최저가", "무조건" without a verifiable source.
4. **One video, one promise.** Each plan has a single viewer problem and a single product answer.
5. **Trends are looked up, not remembered.** Trend analysis uses a current web search or the user's own analytics. Never present remembered trends as current.
6. **Tell the truth about the product.** Include at least one honest limitation (단점 또는 이런 분께는 비추천). It raises trust and conversion.

## Inputs to Collect

Ask once, up front, only for what is missing:

| Input | Why it matters |
|-------|----------------|
| Product name and product page link | Source for all facts |
| Target viewer (나이대, 상황, 고민) | Drives the hook |
| Channel and format (릴스 / 쇼츠 / 틱톡), target length | Pacing and scene count |
| Shooting access (직접 사용 가능 여부, 촬영 환경, 얼굴 노출 여부) | Decides review vs. no-face format |
| Tone (정보형, 공감형, 유머형, ASMR형) | Voice of the script |
| Link method (프로필 링크, 댓글 고정, DM 자동화) | CTA wording |

If the user did not say, default to 20–30 seconds, no-face hands-and-product format, and 정보형 tone.

## Workflow

### Step 1: Trend Check

Run a current search for the product category on the target platform and note:

- 2–3 recurring video formats in the category right now (예: 비포/애프터, 언박싱, 가격 대비 비교, "이거 모르면 손해")
- 2–3 hooks or phrases that repeat across top results
- one saturated angle to avoid and one under-served angle to use

Output a short table: format, why it works, how we adapt it. Cite where each observation came from. If no search is available, ask the user for 3 reference Reels instead and say the trend section is based on those.

### Step 2: Angle and Hook

Pick one angle from the viewer problem, then write **3 hook options** for the first 3 seconds. Use these formulas:

| Formula | Pattern | Example shape |
|---------|---------|---------------|
| 문제 직격 | Name the exact annoyance | "○○ 때문에 매번 ○○하시죠?" |
| 결과 먼저 | Show the result before the product | After shot in frame 1, then "이거 하나로" |
| 숫자 | One concrete, verifiable number | "○분 만에", "○개 중 이것만" |
| 반전 | Common belief, then correction | "○○는 이렇게 쓰면 안 됩니다" |
| 대상 지정 | Call out the viewer | "자취 시작하는 분들, 이것부터 사세요" |

Rules: the first frame must show motion or a result, on-screen text appears within 1 second, and the hook must be true to the product.

### Step 3: Scene-by-Scene Script

Write a table the user can shoot from. Default structure for 25 seconds:

| 컷 | 시간 | 화면 | 자막 | 나레이션/멘트 | 촬영 메모 |
|----|------|------|------|----------------|-----------|
| 1 훅 | 0–3초 | 결과 또는 문제 장면 | 큰 글씨 한 줄 | 훅 멘트 | 클로즈업, 움직임 |
| 2 문제 | 3–8초 | 불편한 상황 | 공감 자막 | 상황 설명 | 사용 전 상태 |
| 3 해결 | 8–16초 | 제품 사용 장면 2–3컷 | 핵심 장점 1–2개 | 장점 설명 | 사용 과정 위주 |
| 4 솔직 한마디 | 16–21초 | 단점 또는 비추천 대상 | 솔직 자막 | 한계 설명 | 신뢰 확보 |
| 5 CTA | 21–25초 | 제품 전체샷 | 링크 위치 안내 | 행동 유도 | 마지막 프레임 유지 |

Keep each cut under 5 seconds, one idea per cut, and write subtitles short enough to read in under 2 seconds. Mark every product fact in the script with its source (`[상품 페이지]`, `[직접 사용]`) or `[확인 필요]`.

### Step 4: Caption, Hashtags, and CTA

Deliver:

- **캡션**: 첫 줄 훅 (2줄 안에 핵심), 본문 2–4줄, CTA, **광고 표기 문구**
- **해시태그**: 8–12개, mix of broad (#쿠팡추천템), category (#자취템 #주방용품), and niche tags; no banned or irrelevant tags
- **고정 댓글**: link guidance and the disclosure repeated
- **CTA 문구**: match the link method. Reels captions do not make links clickable, so point to 프로필 링크, 고정 댓글, or the DM keyword flow the user chose

### Step 5: Shoot Checklist

Produce a checklist the user can tick off on set (see Output Template).

## Compliance

Korean rules expect affiliate content to be marked clearly. Use the Coupang Partners notice in the caption and show it in the video:

```text
이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
```

- Put the notice at the **top or near the top** of the caption, not buried under hashtags
- Also show a short text such as `광고 · 쿠팡 파트너스` on screen for the whole video or the CTA cut
- Do not state a fixed price; prices and stock change. Use "가격은 링크에서 확인" instead
- Do not imply the product is the user's own brand or that Coupang endorses the user
- Check the current Coupang Partners program terms and 공정거래위원회 표시·광고 guidance before publishing, since rules can change

## Anti-Patterns

- Opening with the brand or product name instead of the viewer's problem
- Fake urgency ("오늘만", "곧 품절") that the product page does not show
- Copying a competitor's script line by line instead of adapting the format
- 15 hashtags that are unrelated to the product
- Disclosure placed only after "더보기" or only in hashtags
- Claiming personal use when the product was not used (state "사용해 본 경우에만" for review framing)
- Scripts with five claims and no demonstration

## Best Practices

- Show the product doing the job in the first 8 seconds
- Prefer one strong demo over a feature list
- Reuse the same structure across a batch and vary only the hook and product
- Save the winning hook and format after each upload and compare view and click-through results before the next batch
- Keep a `[확인 필요]` list and clear it before shooting
